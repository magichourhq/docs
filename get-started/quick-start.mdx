Generate one image and save it to your computer. You only need an API key, credits, and Python or Node.js. No input files, webhooks, or app setup are required.

Prefer [creating with an AI assistant](/integration/model-context-protocol) or [using the web app](https://magichour.ai/create?utm_source=docs&utm_medium=referral&utm_campaign=quick-start)? Start there instead. For a browser notebook, open the [Colab cookbook](/get-started/cookbook).

## 1. Get your API key

1. Sign in to the [Developer Hub](https://magichour.ai/developer?tab=api-keys&ref=docs-quickstart&utm_source=docs&utm_medium=referral&utm_campaign=quick-start).
2. Select **Create key**, name it, and copy the key immediately.
3. Set it in the terminal where you will run the example:

<CodeGroup>

```bash macOS / Linux
export MAGIC_HOUR_API_KEY="your_api_key_here"
```

```powershell PowerShell
$env:MAGIC_HOUR_API_KEY = "your_api_key_here"
```

```cmd Windows Command Prompt
set MAGIC_HOUR_API_KEY=your_api_key_here
```

</CodeGroup>

Keep this key on your server or local computer. Do not put it in browser code or commit it to a repository. See [authentication](/get-started/authentication) if you need help creating or managing keys.

<Note>
  This example requests one `flux-2-klein` image at `640px`, a model available on the free tier with
  pricing starting at 5 credits per image. Check your balance and the current [model
  pricing](/api-reference/image-projects/ai-image-generator) before running it. API calls spend
  credits; a free account does not mean unlimited API use.
</Note>

## 2. Copy and run one example

Choose one language. The SDK submits the job, waits for rendering, and downloads the output to your current directory.

<Tabs>
<Tab title="Python">

Install the SDK:

```bash
python -m pip install --upgrade magic_hour
```

Save this as `main.py`:

```python
import os
from magic_hour import Client

client = Client(token=os.environ["MAGIC_HOUR_API_KEY"])

result = client.v1.ai_image_generator.generate(
    model="flux-2-klein",
    image_count=1,
    aspect_ratio="1:1",
    resolution="640px",
    style={"prompt": "A neon ramen shop at night, cinematic photography"},
    wait_for_completion=True,
    download_outputs=True,
    download_directory=".",
)

if result.status != "complete" or not result.downloaded_paths:
    raise RuntimeError(f"No downloaded result: project {result.id}, status {result.status}")

print(f"Project: {result.id}")
print(f"Credits charged: {result.credits_charged}")
print(f"Saved files: {result.downloaded_paths}")
```

Run it from the same directory:

```bash
python main.py
```

</Tab>
<Tab title="Node.js">

Install the SDK:

```bash
npm install magic-hour
```

Save this as `main.mjs`. The `.mjs` extension enables imports without changing your project's configuration.

```javascript
import { Client } from "magic-hour";

if (!process.env.MAGIC_HOUR_API_KEY) {
  throw new Error("Set MAGIC_HOUR_API_KEY in this terminal first.");
}

const client = new Client({ token: process.env.MAGIC_HOUR_API_KEY });

const result = await client.v1.aiImageGenerator.generate(
  {
    model: "flux-2-klein",
    imageCount: 1,
    aspectRatio: "1:1",
    resolution: "640px",
    style: { prompt: "A neon ramen shop at night, cinematic photography" },
  },
  {
    waitForCompletion: true,
    downloadOutputs: true,
    downloadDirectory: ".",
  }
);

if (result.status !== "complete" || !result.downloadedPaths?.length) {
  throw new Error(`No downloaded result: project ${result.id}, status ${result.status}`);
}

console.log(`Project: ${result.id}`);
console.log(`Credits charged: ${result.creditsCharged}`);
console.log(`Saved files: ${result.downloadedPaths.join(", ")}`);
```

Run it from the same directory:

```bash
node main.mjs
```

</Tab>
</Tabs>

Using another language? The [image generation reference](/api-reference/image-projects/ai-image-generator) includes cURL and other SDK request examples. For direct REST calls, create the image, retain its `id`, then [get the image project](/api-reference/image-projects/get-image-details) until its status is `complete` and download `downloads[].url`.

## 3. Open your image

When the script succeeds, it prints the project ID, credits charged, and saved file paths. Open a file at the printed path. You can also find the creation in [My Library](https://magichour.ai/my-library?utm_source=docs&utm_medium=referral&utm_campaign=quick-start).

Rendering is asynchronous: a project ID alone is not a finished image. Keep the script running while it waits. Processing time varies with the model and queue; see [recent processing times](/api-reference/processing-times).

## If something goes wrong

| What you see                     | What to do                                                                                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Missing API key or `401`         | Set the variable in the same terminal, and verify the key is active.                                                                           |
| `400` or `422`                   | Read the response message and correct the named input field.                                                                                   |
| `402`                            | Check your credit balance in the [Developer Hub](https://magichour.ai/developer?utm_source=docs&utm_medium=referral&utm_campaign=quick-start). |
| `403`                            | Check whether your plan supports the requested model and resolution.                                                                           |
| `429`                            | Wait and retry with backoff.                                                                                                                   |
| Timeout or `5xx` during creation | Check whether a project was created before submitting again; repeating a creation request can create another paid job.                         |
| Render error                     | Keep the project ID and read the returned error. Fix the cause before creating another project.                                                |
| No local file                    | Check the printed status and paths. A custom download directory must already exist.                                                            |

If you have a project ID, check [that project's status](/api-reference/image-projects/get-image-details) instead of starting over. For persistent failures, send the project ID and error to [support@magichour.ai](mailto:support@magichour.ai).
