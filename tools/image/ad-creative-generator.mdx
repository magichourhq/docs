AI Ad Creative Generator creates a grid of campaign concepts from an uploaded image. An optional prompt can describe the audience, offer, placement, or visual direction.

[Open AI Ad Creative Generator](https://magichour.ai/products/ai-ad-creative-generator)

## How to use it

1. Upload the product or subject image.
2. Describe the campaign and choose an available output format.
3. Generate the concept grid, compare the layouts, and download promising options.

## Example prompt

```text
Create a square launch concept for this ceramic mug. Use warm kitchen lighting, a cream palette, and empty space above the product for a headline.
```

## Check the result

Check product details, logos, and generated text. Add approved copy before publishing.

## API availability

The [public API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated Ad Creative Generator endpoint. Use [AI Image Editor](/api-reference/image-projects/ai-image-editor) for custom image-based concepts; it does not expose the website ad-grid workflow.
