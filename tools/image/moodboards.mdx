Moodboards saves inspiration images as a style reference. Use images with the palette, texture, lighting, and composition you want to generate.

[Open Moodboards](https://magichour.ai/products/moodboards)

## How to use it

1. Upload inspiration images that share a visual style.
2. Arrange the images, name the Moodboard, and save it.
3. Choose it from References in a supported image or video tool. Select multiple boards to blend styles.

## Choosing references

Keep distinct styles in separate boards so you can compare their effect on generated images.

## API availability

The [public API specification](https://magichour.ai/docs/api/openapi.json) does not document Moodboard creation, management, or a Moodboard-ID input. Use the website for saved Moodboards; API reference-image support is specific to each generation endpoint.
