Image Enhancer opens the Photo Enhancer workspace, which has Photo, Upscale, Retouch, and Skin treatments. The initial Photo view offers Subtle, Balanced, and Realistic modes.

[Open Image Enhancer](https://magichour.ai/create/photo-enhancer)

## How to use it

1. Upload a photo.
2. Select Photo, Upscale, Retouch, or Skin.
3. Choose a mode and resolution, then review the credit cost. Available controls and costs depend on the treatment and settings.
4. Generate the image and compare facial details, textures, and edges with the source at full size before downloading.

## API availability

The [public API specification](https://magichour.ai/docs/api/openapi.json) does not expose a dedicated Photo Enhancer endpoint. For API upscaling, use [AI Image Upscaler](/api-reference/image-projects/ai-image-upscaler); its documented modes differ from the Photo Enhancer interface.
