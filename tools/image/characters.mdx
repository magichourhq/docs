Characters saves photos of a recurring subject so you can reuse them without uploading them for each generation. When you select a Character in a supported tool, Magic Hour uses its primary image or an automatically assembled collage.

[Open Characters](https://magichour.ai/products/characters)

## How to use it

1. Create a Character with 1 to 12 clear photos of the same person or character.
2. Give it a name and choose the primary photo.
3. Open Text-to-Video, Image-to-Video, AI Image Editor, or AI Image Generator and select the Character from References.

## Reference photos

Include varied angles and expressions. Check likeness in each result; references do not guarantee identical details.

## API availability

The [public API specification](https://magichour.ai/docs/api/openapi.json) does not document Characters library management or a Character-ID parameter. For API work, use the image/reference fields documented for the selected generation endpoint.
