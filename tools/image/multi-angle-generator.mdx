AI Multi-Angle Photo Generator creates new views of a product, person, or object. Available directions include front, side, three-quarter, overhead, close-up, and wider views.

[Open AI Multi-Angle Photo Generator](https://magichour.ai/products/ai-multi-angle-generator)

## How to use it

1. Upload an image of the subject.
2. Choose or describe the camera perspective you want.
3. Generate angle variations, compare the views, and download a selected result.

## Example prompt

```text
Show this chair from a three-quarter front view at seat height. Keep the upholstery, leg design, and proportions consistent.
```

## Check the result

Use a source image that shows the subject's defining details. The tool must invent unseen surfaces, so check their accuracy along with proportions and geometry across views.

## API availability

There is no dedicated Multi-Angle Generator endpoint in the [public API specification](https://magichour.ai/docs/api/openapi.json). [AI Image Editor](/api-reference/image-projects/ai-image-editor) supports custom perspective prompts; the website angle presets are not separate documented API operations.
