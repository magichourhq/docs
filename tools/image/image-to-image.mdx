Image-to-Image uses an uploaded image as the starting point for a new variation. Choose a preset or describe the transformation you want.

[Open Image-to-Image](https://magichour.ai/products/image-to-image)

## How to use it

1. Upload the image you want to transform.
2. Choose a style preset or enter a prompt describing the new look.
3. Generate a variation, review it against the source, and download your preferred result.

## Example prompt

```text
Turn this storefront sketch into a watercolor illustration. Keep the doorway and windows in their current positions.
```

## Writing the prompt

Name the elements you want to preserve in the prompt, then check them in the result. Change one style direction at a time to compare its effect.

## API availability

For programmatic transformations, use [AI Image Editor](/api-reference/image-projects/ai-image-editor). The website links to this API. The [public API specification](https://magichour.ai/docs/api/openapi.json) has no separate Image-to-Image endpoint.
