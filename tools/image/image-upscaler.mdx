## Overview

AI Image Upscaler enlarges an image by 2x or 4x. It can reconstruct edges and textures, but it cannot recover detail missing from the source image.

## How It Works

1. Provide the source image.
2. Choose a 2x or 4x scale factor.
3. The API enlarges the image and reconstructs edges and textures.
4. Download the result.

## Use Cases

- **Print preparation** - Enlarge low-resolution images for print layouts
- **E-commerce** - Enlarge product photos for web display
- **Photo restoration** - Upscale old or degraded images
- **Large format displays** - Prepare images for billboards or banners
- **Archives** - Enlarge historical or archival images

## Best Practices

### Input Image Quality

<Tip>
  **Start with the best source available** - Compression, blur, and other defects remain visible and
  may become more pronounced after upscaling.
</Tip>

- **Avoid heavily compressed images** - JPEG artifacts will be amplified
- **Use original files when possible** - Avoid screenshots of screenshots
- **Check for existing blur** - AI can't recover details that aren't there

### Scale Factor Selection

| Scale Factor | Output Size         | Typical use                       |
| :----------- | :------------------ | :-------------------------------- |
| 2x           | 2× width, 2× height | Minor enhancement, web use        |
| 4x           | 4× width, 4× height | Print preparation, large displays |

A 2x scale produces four times as many pixels. A 4x scale produces sixteen times as many.

### Input considerations

**Generally easier:**

- Photographs with clear subjects
- Artwork and illustrations
- Product images
- Portraits and faces

**Likely to show artifacts:**

- Heavily compressed images (visible artifacts)
- Very blurry images
- Text-heavy images (use vector formats instead)

## Code Examples

### Basic 2x Upscaling

<CodeGroup>

```python Python
from magic_hour import Client
from os import getenv

client = Client(token=getenv("MAGIC_HOUR_API_KEY"))

result = client.v1.ai_image_upscaler.generate(
    assets={
        "image_file_path": "https://raw.githubusercontent.com/runshouse/Sample_Assets/main/sea.jpg"
    },
    scale_factor=2.0,
    style={
        "mode": "balanced"
    },
    name="Image Upscaler image",
    wait_for_completion=True,
    download_outputs=True,
    download_directory="."
)

if result.status == "complete":
    print(f"✅ Upscale complete!")
    print(f"Downloaded to: {result.downloaded_paths}")
    print(f"Credits charged: {result.credits_charged}")
else:
    print(f"❌ Job failed with status: {result.status}")
    if hasattr(result, 'error_message'):
        print(f"Error: {result.error_message}")
```

```javascript Node.js
import { Client } from "magic-hour";

const client = new Client({ token: process.env.MAGIC_HOUR_API_KEY });

const result = await client.v1.aiImageUpscaler.generate({
  assets: {
    imageFilePath: "https://raw.githubusercontent.com/runshouse/Sample_Assets/main/sea.jpg",
  },
  scaleFactor: 2.0,
  style: {
    mode: "balanced",
  },
  name: "Image Upscaler image",
  waitForCompletion: true,
  downloadOutputs: true,
  downloadDirectory: ".",
});

console.log(`✅ Upscale complete!`);
console.log(`Status: ${result.status}`);
console.log(`Downloaded to: ${result.downloadedPaths}`);
console.log(`Credits charged: ${result.creditsCharged}`);
```

</CodeGroup>
