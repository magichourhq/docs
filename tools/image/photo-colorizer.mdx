## Overview

Photo Colorizer estimates colors for black and white or grayscale images. It uses objects, lighting, and common color patterns as context, so the result is a plausible interpretation rather than a record of the original colors.

## How It Works

1. Provide a black and white or grayscale image.
2. The model analyzes objects, lighting, and surrounding details.
3. The model estimates colors for the image.
4. Download the colorized result.

## Use Cases

- **Family photos** - Create colorized versions of black and white photos
- **Historical archives** - Create colorized interpretations of historical photographs
- **Artistic projects** - Add color to vintage imagery

## Best Practices

### Photo Selection

<Tip>Use a clean scan. Better source images preserve more detail in the colorized result.</Tip>

- **Clear contrast** - Distinct boundaries help reduce color bleeding
- **High resolution** - More detail gives the model clearer object boundaries
- **Clean scans** - Remove dust and damage first if possible
- **Sharp focus** - Clear edges reduce ambiguous regions

### Typical results

| Photo type     | What to expect                                  |
| :------------- | :---------------------------------------------- |
| Portraits      | Skin, hair, and clothing colors are estimated   |
| Natural scenes | Foliage, sky, and ground colors are estimated   |
| Architecture   | Materials and painted surfaces may vary         |
| Objects        | Uncommon objects may receive unexpected colors  |
| Complex scenes | More objects can increase inconsistent coloring |

## Code Examples

### Colorize Black & White Photo

<CodeGroup>

```python Python
from magic_hour import Client
from os import getenv

client = Client(token=getenv("MAGIC_HOUR_API_KEY"))

result = client.v1.photo_colorizer.generate(
    assets={
        "image_file_path": "https://raw.githubusercontent.com/runshouse/Sample_Assets/main/v-j-day-in-times-square.jpg"
    },
    name="Photo Colorizer image",
    wait_for_completion=True,
    download_outputs=True,
    download_directory="."
)

if result.status == "complete":
    print(f"✅ Colorization complete!")
    print(f"Downloaded to: {result.downloaded_paths}")
    print(f"Credits charged: {result.credits_charged}")
else:
    print(f"❌ Job failed with status: {result.status}")
    if hasattr(result, 'error_message'):
        print(f"Error: {result.error_message}")
```

```javascript Node.js
import { Client } from "magic-hour";

const client = new Client({ token: process.env.MAGIC_HOUR_API_KEY });

const result = await client.v1.photoColorizer.generate({
  assets: {
    imageFilePath: "https://raw.githubusercontent.com/runshouse/Sample_Assets/main/bw-photo.jpg",
  },
  name: "Photo Colorizer image",
  waitForCompletion: true,
  downloadOutputs: true,
  downloadDirectory: ".",
});

console.log(`✅ Colorization complete!`);
console.log(`Status: ${result.status}`);
console.log(`Downloaded to: ${result.downloadedPaths}`);
```
