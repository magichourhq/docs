AI Photo Relighting creates alternate lighting treatments for portraits, products, interiors, and other photos. The default website workflow keeps the input aspect ratio.

[Open AI Photo Relighting](https://magichour.ai/products/ai-photo-relighting)

## How to use it

1. Upload the photo you want to relight.
2. Describe the light direction, intensity, color temperature, or time of day.
3. Generate variations, compare the lighting, and download your preferred result.

## Example prompt

```text
Add a large soft light from the upper left, gentle shadows, and neutral color temperature. Keep the framing and subject unchanged.
```

## Check the result

Check that highlights and shadows match the requested light direction. Compare skin tones or product colors with the source.

## API availability

There is no dedicated Photo Relighting endpoint in the [public API specification](https://magichour.ai/docs/api/openapi.json). Use [AI Image Editor](/api-reference/image-projects/ai-image-editor) for custom lighting edits through text prompts.
