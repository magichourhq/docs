AI Product Photography uses a product photo to create new scenes, surfaces, backgrounds, and lighting setups. The website presents variations in a grid for comparison.

[Open AI Product Photography](https://magichour.ai/products/ai-product-photography)

## How to use it

1. Upload a clear, unobstructed product photo.
2. Choose a studio, lifestyle, editorial, or marketplace direction and optionally add a prompt.
3. Select the output shape for your intended placement and generate product shots.
4. Compare labels, shape, color, and materials with the original before downloading.

## Example prompt

```text
Place this bottle on pale stone with soft window light from the left. Keep the bottle shape, label, and cap unchanged.
```

## API availability

There is no dedicated Product Photography endpoint in the [public API specification](https://magichour.ai/docs/api/openapi.json). For custom product-image edits, use [AI Image Editor](/api-reference/image-projects/ai-image-editor) with your own prompt.
