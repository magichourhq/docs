AI Influencer Generator creates a fictional, photorealistic persona from appearance selections such as hair, eyes, age, and style. No source portrait is required.

[Open AI Influencer Generator](https://magichour.ai/products/ai-influencer-generator)

## How to use it

1. Select appearance traits.
2. Generate a portrait and adjust the traits as needed.
3. Save or locate the persona in Characters, then select it from References in a supported creation tool.

## API availability

The [public API specification](https://magichour.ai/docs/api/openapi.json) does not document an Influencer Generator endpoint or Characters library management. Use the website for trait selection and saved-persona workflows.
