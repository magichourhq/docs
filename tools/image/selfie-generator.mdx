AI Selfie Generator applies a selected artistic style to one uploaded portrait. It offers looks such as anime, cartoon, and themed portraits.

[Open AI Selfie Generator](https://magichour.ai/products/ai-selfie-generator)

## How to use it

1. Upload a clear photo with the face visible.
2. Choose a style preset and generate a selfie.
3. Review the portrait, try another style if needed, and download the result.

## Check the result

Use even lighting and an unobstructed face. Compare the generated eyes, mouth, and facial outline with the source.

## API availability

There is no dedicated Selfie Generator endpoint in the [public API specification](https://magichour.ai/docs/api/openapi.json). For custom portrait transformations, use [AI Image Editor](/api-reference/image-projects/ai-image-editor) with your own prompt; its controls differ from the website presets.
