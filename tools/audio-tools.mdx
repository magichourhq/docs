## Music generation

Music costs 1 credit per requested second. Set `duration` and `style.prompt`; use
`style.instrumental: true` for music without vocals, or supply `style.lyrics` for custom lyrics.

The create response returns a project ID. Keep it and poll
[Get Audio Details](/api-reference/audio-projects/get-audio-details) until the project is
`complete`, then retrieve the result from `downloads`.
