## Overview

[AI Avatar Generator](https://magichour.ai/products/ai-avatar-generator) creates presenter videos from a portrait or available Character, an optional background, and either a script with a selected voice or uploaded audio. See the [current editor guide](https://help.magichour.ai/en/articles/16917129-ai-avatar-generator-step-by-step-guide).

## How it works

1. Upload a portrait or select an available Character.
2. Choose an optional background, or select Original to keep the original setting.
3. Enter Script and choose Voice, or select Add Audio and provide a recording.
4. Select a mode and check the displayed duration limit. Shorten your input if needed.
5. Review the credit estimate, generate the video, and check the result before downloading.

The editor prepares the opening image as needed. Follow its prompts instead of the older first-frame wizard.

Keep the script within the selected duration, including pauses. Check pronunciation of names and abbreviations in a short sample.

## API availability

The [published API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated Avatar Generator endpoint.

[Talking Photo](/api-reference/video-projects/ai-talking-photo) supports animating an image with supplied audio. It is a related building block, without the Avatar editor's combined background and script controls.
