## Overview

[AI Video Translator](https://magichour.ai/products/ai-video-translator) translates spoken dialogue, recreates it in the speaker's voice, and aligns lip movements to the new audio. The website currently lists 53 supported languages.

## How It Works

1. **Upload a video** - Choose footage containing clear spoken dialogue.
2. **Select a target language** - Use the language selector on the product page.
3. **Generate the translation** - The tool transcribes and translates speech, generates the voice track, and aligns the lips.
4. **Review and download** - Check meaning, pronunciation, and synchronization before sharing.

## Use Cases

- **Courses and tutorials** - Adapt recorded lessons for another language.
- **Product demos** - Localize walkthroughs for regional audiences.
- **Social content** - Create language-specific versions of an existing clip.

## Best Practices

<Tip>
  Have a fluent speaker review the result, especially names, numbers, and specialist terminology.
</Tip>

- Use clear dialogue with minimal competing music or background noise.
- Start with a short sample before translating an entire content library.
- Review translated speech in context; an accurate sentence can still sound unnatural.
- Check any text already visible in the video separately from the spoken translation.

## Translation and Dubbing

Magic Hour combines language conversion and voice replacement. [Video Dubbing](/tools/video/video-dubbing) presents the same combined process from the perspective of creating a replacement voice track. Subtitle generation is a separate workflow.

## API Availability

The [published API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated Video Translator endpoint.

The [Lip Sync API](/api-reference/video-projects/lip-sync) accepts supplied audio for a video. It does not translate dialogue or generate translated speech.
