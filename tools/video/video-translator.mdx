## Overview

[AI Video Translator](https://magichour.ai/products/ai-video-translator) translates spoken dialogue, recreates it in the speaker's voice, and aligns lip movements to the new audio. The website currently lists 53 supported languages.

## How it works

1. Upload a video with clear spoken dialogue.
2. Select a target language.
3. Generate the translation. The tool transcribes and translates speech, generates the voice track, and aligns lip movements.
4. Check meaning, pronunciation, and synchronization before downloading.

Have a fluent speaker check names, numbers, and specialist terms. Check visible text separately from the spoken translation.

## Translation and dubbing

Magic Hour combines language conversion and voice replacement. [Video Dubbing](/tools/video/video-dubbing) presents the same combined process from the perspective of creating a replacement voice track. Subtitle generation is a separate workflow.

## API availability

The [published API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated Video Translator endpoint.

The [Lip Sync API](/api-reference/video-projects/lip-sync) accepts supplied audio for a video. It does not translate dialogue or generate translated speech.
