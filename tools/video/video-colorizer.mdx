## Overview

[Video Colorizer](https://magichour.ai/products/video-colorizer) adds AI-generated color to black-and-white and grayscale videos. Choose Subtle, Balanced, or Strong to control the intensity of the result.

## How It Works

1. **Upload grayscale footage** - Start with a home movie, film scan, or other black-and-white video.
2. **Choose a strength** - Select muted, balanced, or vivid coloring.
3. **Generate the result** - AI estimates colors from the visual context.
4. **Review and download** - Check faces, clothing, backgrounds, and scene changes.

## Use Cases

- **Family archives** - Create color versions of older recordings.
- **Documentary edits** - Explore a color treatment for archival material.
- **Creative projects** - Compare muted and vivid interpretations of a grayscale scene.

## Best Practices

<Tip>Preserve the original grayscale file alongside the colorized version.</Tip>

- Start with the clearest source available; extreme grain can obscure visual details.
- Compare several points in a shot to check that colors stay consistent.
- Evaluate skin tones and neutral objects before choosing a stronger setting.
- If historical accuracy matters, compare generated colors with independent reference material.

## Understanding the Output

Generated color is an interpretation. A plausible result does not verify the original colors of clothing, objects, or locations.

## API Availability

The [published API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated Video Colorizer endpoint.

The [Photo Colorizer API](/api-reference/image-projects/photo-colorizer) accepts still images. It does not provide the website's video-colorization workflow.
