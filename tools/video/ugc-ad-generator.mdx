## Overview

[AI UGC Ad Generator](https://magichour.ai/products/ai-ugc-ad-generator) creates actor-led video ads. The current single-page editor combines an actor image, optional product image, Script, and optional Action prompt. See the [current editor guide](https://help.magichour.ai/en/articles/12613176-ai-ugc-ads-make-a-presenter-style-video-with-your-own-actor).

## How it works

1. Select a provided actor or upload a creator image.
2. Upload an optional product image.
3. Put spoken words in Script and visual instructions in Action prompt.
4. Select a model, duration, aspect ratio, and resolution.
5. Check the credit estimate, generate the video, and review it in History or My Library.

Check product appearance, pronunciation, and pacing in the generated video.

### Using recorded audio

LTX-2.3 supports uploaded script audio. The current LTX-2.5 script workflow does not. Recheck settings after switching models; longer scripts do not increase the selected duration. See the [editor guide](https://help.magichour.ai/en/articles/12613176-ai-ugc-ads-make-a-presenter-style-video-with-your-own-actor) for current controls.

## Language support

The product page notes that language support varies by model. Preview the actual output for each language instead of assuming every model supports the same scripts.

## API availability

The [published API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated UGC Ad Generator endpoint.

[Talking Photo](/api-reference/video-projects/ai-talking-photo) can animate an image with supplied audio. It does not expose the UGC editor's actor/product selection and script workflow.

## Access and pricing

The full editor requires sign-in and uses credits. Follow its displayed access options and estimate. See [website pricing](https://magichour.ai/pricing) for plans.
