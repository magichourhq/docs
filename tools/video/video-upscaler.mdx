## Overview

[AI Video Upscaler](https://magichour.ai/products/video-upscaler) increases video resolution, sharpens details, and reduces blur. The website supports MOV and MP4 uploads, 2× or 4× upscaling, and target resolutions from 720p to 4K. A paid plan is required.

## How It Works

1. **Upload your video** - Start with the best available source file.
2. **Select an output size** - Choose an upscaling factor or target resolution.
3. **Render the video** - Generate the enhanced version.
4. **Review and download** - Compare the result with the original before exporting.

## Use Cases

- **Older recordings** - Prepare low-resolution footage for larger displays.
- **Product clips** - Improve detail in videos for storefronts and landing pages.
- **Cropped footage** - Enhance clips that became softer after reframing.

## Best Practices

<Tip>
  Compare a representative section at its intended playback size before processing your full
  collection.
</Tip>

- Keep the original file so you can compare textures, faces, and motion.
- Check moving edges and fine patterns for artifacts throughout the result.
- Avoid repeatedly compressing a clip between editing steps.
- Choose the resolution needed for delivery; a larger file alone does not establish better visual quality.

## API Availability

The [published API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated Video Upscaler endpoint.

The [Image Upscaler API](/api-reference/image-projects/ai-image-upscaler) processes still images. It is not a video-upscaling endpoint.
