## Overview

[AI Video Extender](https://magichour.ai/products/ai-video-extender) generates additional footage at the end of a video. The free website tool creates a five-second continuation automatically; the signed-in tool offers optional prompt and audio guidance.

## How it works

1. Upload a clip with a clear final shot.
2. Generate an extension. The model uses the existing scene and motion to create a continuation.
3. Watch the join between the original footage and the generated section.
4. Download the result.

Trim any unwanted cut at the end of the source. Check the subject and motion at the join, and review the output audio.

## Extending and expanding

Video Extender adds duration. To change frame shape or make more room around the subject, use [Video Expander](/tools/video/video-expander).

## API availability

The [published API specification](https://magichour.ai/docs/api/openapi.json) has no dedicated Video Extender endpoint.

[Image to Video](/api-reference/video-projects/image-to-video) generates a new clip from an image. It does not expose the website's existing-video extension workflow.
