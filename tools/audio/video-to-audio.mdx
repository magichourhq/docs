## Overview

[Video-to-Audio](https://magichour.ai/products/video-to-audio) analyzes video frames and generates new audio that follows the action. Use it for Foley, environmental sound, or a soundtrack for silent footage.

## How it works

1. Upload a video with clearly visible action.
2. Generate audio and review how the sound matches the motion.
3. Download the result. The free preview returns a video with generated audio; the full tool provides an audio download for editing.

The full tool also offers an optional prompt to guide the audio style. For example, request subtle ambience and footsteps for a walking scene.

This tool generates new sound rather than extracting the existing soundtrack.

## Availability and pricing

Use the [web tool](https://magichour.ai/products/video-to-audio) for current preview limits and available controls. Longer clips and additional controls depend on the selected plan.

## API availability

Video-to-Audio is available in the web app. The published [API reference](/api-reference/overview) does not include a video-to-audio creation endpoint.
