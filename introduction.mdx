## From request to finished file

1. **Choose the tool and inputs.** The tool guide explains what you need; its API reference lists required fields and supported models.
2. **Create one project.** A successful API creation request returns a project ID. Rendering continues asynchronously.
3. **Wait for completion.** Use the SDK's `generate()` helper, MCP's matching wait helper, or poll the project status endpoint.
4. **Save the result.** Download the completed output. Keep signed download URLs exactly as returned.

Your API creations also appear in [My Library](https://magichour.ai/my-library?utm_source=docs&utm_medium=referral&utm_campaign=introduction).
