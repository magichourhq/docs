# Prepared listing copy

Status: development implementations; no marketplace submission or approval is claimed.

## Framer

**Name:** Magic Hour Video

**Summary:** Create short hero and background videos from your images or creative brief.

**Description:** Select an image, describe its motion, and generate a video with Magic Hour. Preview the result, then add a native Framer video component with muted looping playback. You can also start from a text brief. Stop waiting and resume a saved project without creating another generation. Source images stay in place. Seamless visual looping is not guaranteed.

## Adobe Express — stable version

**Name:** Magic Hour Video

**Summary:** Animate an uploaded image or your current page and add the video to your design.

**Description:** Choose your own image file or explicitly export the current page, describe the motion, and generate a video with Magic Hour. Preview and add the finished video to Adobe Express. Export restrictions are respected, and a saved project can be resumed without a new generation. The public version does not capture individual selected elements; that Adobe API is experimental.

## Canva

**Name:** Magic Hour Video

**Summary:** Turn an image or creative brief into a short video for your design.

**Description:** Choose one image, describe its motion, and generate a video with Magic Hour. Preview the completed video and add it to your Canva design as a native video. You can also upload an image or start from text. Canva provides the full original selected image, including areas outside a visible crop. Saved project IDs let you resume waiting without another generation. Generated videos are disclosed as AI-generated during import.

## Shared account and privacy disclosures

Requires a Magic Hour account, API key, and sufficient API credits. The app/plugin is free; Magic Hour API usage has separate pricing and plan requirements. Entered API keys stay in session memory. Prompts and the chosen source image are sent to Magic Hour for processing. The latest accepted project ID is saved locally for recovery. The output is copied into the editor when the user chooses Add.
