---
title: Idempotent Requests
description: Safely retry project create requests without creating or paying for a second project.
---

Project create endpoints accept an `Idempotency-Key` header, so you can safely retry a request after a timeout or connection error. Repeating a key within 24 hours returns the original project instead of creating and charging for a new one.

Keys are shared across all video, image, and audio endpoints on your account. Use a new key, such as a UUID, for each project, and reuse it only to retry that request.

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.magichour.ai/v1/ai-image-generator \
  --header 'authorization: Bearer <token>' \
  --header 'content-type: application/json' \
  --header 'Idempotency-Key: 5f3c1b9e-8a41-4a0e-9d3e-2f6a1c7b9e10' \
  --data '{"image_count": 1, "style": {"prompt": "Cool image"}}'
```

```python Python SDK
client.v1.ai_image_generator.create(
    image_count=1,
    style={"prompt": "Cool image"},
    request_options={"additional_headers": {"Idempotency-Key": "5f3c1b9e-8a41-4a0e-9d3e-2f6a1c7b9e10"}},
)
```

```typescript Node.js SDK
await client.v1.aiImageGenerator.create(
  { imageCount: 1, style: { prompt: "Cool image" } },
  { additionalHeaders: { "Idempotency-Key": "5f3c1b9e-8a41-4a0e-9d3e-2f6a1c7b9e10" } },
);
```

```go Go SDK
res, err := client.V1.AiImageGenerator.Create(
	ai_image_generator.CreateRequest{
		ImageCount: 1,
		Style:      types.V1AiImageGeneratorCreateBodyStyle{Prompt: "Cool image"},
	},
	func(req *http.Request) error {
		req.Header.Set("Idempotency-Key", "5f3c1b9e-8a41-4a0e-9d3e-2f6a1c7b9e10")
		return nil
	},
)
```

</CodeGroup>

In the Python and Node.js SDKs, `generate()` accepts the same option. The Rust SDK can't send custom headers yet.
