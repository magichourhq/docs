The Magic Hour provider supports AI SDK v7 image generation and experimental video generation, including text-to-video and image-to-video. It uses the public API and handles uploads, asynchronous completion, and output downloads.

<Note>
  The provider is distributed as a GitHub-hosted package archive. npm publication remains pending.
</Note>

## Install

```sh
npm install https://github.com/magichourhq/docs/releases/download/ai-sdk-provider-v0.1.1/magichourhq-ai-sdk-provider-0.1.1.tgz ai@7.0.148
```

Requires Node.js 22 or newer. Version 0.1.1 was checked with `ai@7.0.148` and `@ai-sdk/provider@4.0.31`. Video APIs are experimental; retest before upgrading. The [GitHub release](https://github.com/magichourhq/docs/releases/tag/ai-sdk-provider-v0.1.1) includes the package checksum. The previous [version 0.1.0 archive](https://github.com/magichourhq/docs/releases/tag/ai-sdk-provider-v0.1.0) remains available and uses the old import name, `@magichour/ai-sdk-provider`.

```ts
import { generateImage } from "ai";
import { createMagicHour } from "@magichourhq/ai-sdk-provider";

const magichour = createMagicHour(); // Reads MAGIC_HOUR_API_KEY server-side.
const { image } = await generateImage({
  model: magichour.image("flux-2-klein"),
  prompt: "A blue ceramic mug in a sunlit studio",
  aspectRatio: "1:1",
  providerOptions: { magichour: { resolution: "640px" } },
  maxRetries: 0,
});
```

Generations consume Magic Hour credits. Persist the project ID in `onProjectCreated` before waiting. If waiting fails, retrieve the existing project instead of submitting another generation. See the source guide for video examples, supported options, and compatibility versions.
