The Magic Hour provider adds image generation and video generation, from text or from an image, to AI SDK 7. It handles uploads, waiting for the job and downloading the result.

## Install

```sh
npm install @magichourhq/ai-sdk-provider ai
```

Requires AI SDK 7 and Node.js 22 or newer.

## Usage

Set `MAGIC_HOUR_API_KEY` in your terminal and save this as `generate.mjs`. Keep the key server-side.

```js
import { writeFile } from "node:fs/promises";
import { experimental_generateVideo as generateVideo, generateImage } from "ai";
import { magichour } from "@magichourhq/ai-sdk-provider";

const { image } = await generateImage({
  model: magichour.image("flux-2-klein"),
  prompt: "A blue ceramic mug in a sunlit studio",
  aspectRatio: "1:1",
});

const { video } = await generateVideo({
  model: magichour.video("ltx-2.5"),
  prompt: { image: image.uint8Array, text: "A slow camera push toward the mug" },
});

await writeFile("magic-hour-video.mp4", video.uint8Array);
```

Run `node generate.mjs`, then open `magic-hour-video.mp4` in the same folder.

For text-to-video, pass a string prompt.

Generations consume Magic Hour credits, and the provider never retries a paid request. Once a job is accepted, every error is a `MagicHourError` with its `projectId`. Retrieve that project instead of generating again. To keep the ID even if your process stops, save it in `onProjectCreated`:

```ts
import { createMagicHour } from "@magichourhq/ai-sdk-provider";

const magichour = createMagicHour({
  onProjectCreated: ({ id, kind }) => saveProject(id, kind),
});
```
