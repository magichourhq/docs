---
title: Haystack
description: Create an image once, then recover and download it with native Haystack Pipeline components.
---

Magic Hour's image-only Haystack integration provides generation, polling, and download components.
Initial support creates one square 640-pixel Z-Image Turbo image. Generations consume Magic Hour
credits; no LLM provider is required.

## Install and configure

Requires Python 3.11 or newer and Haystack 3.0 or newer. Install the package from PyPI.

```bash
python -m pip install magic-hour-haystack
```

Create an [API key](https://magichour.ai/developer?tab=api-keys) and provide it through your secret
manager as `MAGIC_HOUR_API_KEY` in the process environment. The generator and waiter default to
Haystack's `Secret.from_env_var("MAGIC_HOUR_API_KEY")`; serialized pipelines retain the variable
name, not its value. Keep keys out of source, shell history, and saved pipeline definitions.

## Create once, then resume

Download and run the [image Pipeline example](https://github.com/magichourhq/magic-hour-haystack/blob/v0.1.1/examples/image_pipeline.py).

```bash
curl -fsSL https://raw.githubusercontent.com/magichourhq/magic-hour-haystack/v0.1.1/examples/image_pipeline.py -o image_pipeline.py
HAYSTACK_TELEMETRY_ENABLED=false python image_pipeline.py --output-dir output/bird --submit-only
HAYSTACK_TELEMETRY_ENABLED=false python image_pipeline.py --output-dir output/bird
```

The run with `--submit-only` submits one paid image generation and saves the accepted project ID
and charged credits in `output/bird/project.json` before polling. The next run uses that ID in a
separate status and download Pipeline and saves the image as `image-1.bin`. Inspect the image format
before renaming it.

Keep `project.json` and reuse the same output directory after a timeout or download failure.
Repeating the run without `--submit-only` retrieves the existing project without submitting
another generation.
A missing receipt causes creation, so use a new output directory only when you intend another paid
job. If creation loses its response, check the Developer Hub before submitting again: the service
may have accepted a job whose ID the example could not save.

The downloader returns native Haystack `ByteStream` objects, keeps signed download URLs intact,
and sends no API authorization to media storage. A fresh status lookup refreshes temporary links.
Prompts are sent to Magic Hour for generation; see our [privacy policy](https://magichour.ai/privacy-policy).

## Scope and validation

The original source-install validation used Haystack 3.4.1. One submission charged 5 credits,
and two later runs recovered the same saved project. Both downloaded the same usable 640×640 PNG
without another creation. This initial integration does not support video, audio, uploaded inputs,
or configurable image models and sizes.

See the [source guide](https://github.com/magichourhq/magic-hour-haystack/tree/v0.1.1)
for component APIs, trusted-module pipeline loading, and security limits. The [Haystack community listing](https://github.com/deepset-ai/haystack-integrations/pull/678)
is submitted for review; catalog acceptance is pending.
